Nombre del proyecto: Ciber Guardianes. Nombres completos de los integrantes: Acosta Romina y Pedroncino Cecilia. Problema y destinatarios: En la actualidad, los niños interactúan activamente en plataformas de juego en línea (como Roblox, Minecraft o Brawl Stars), exponiéndose a riesgos severos como contacto no supervisado con desconocidos, microtransacciones impulsivas no autorizadas y contenidos inadecuados para su etapa de desarrollo. Los padres, tutores y educadores requieren una herramienta informática centralizada para catalogar, evaluar y administrar los niveles de riesgo y permisos de acceso de cada videojuego. Utilidad de la solución: Para resolver este problema práctico, se amplía la entidad genérica Registro provista en la plantilla inicial del laboratorio, transformándola en la entidad de dominio JuegoSeguro. Esta adaptación no se limita a un mero cambio cosmético o de etiquetas, sino que incorpora atributos específicos de ciberseguridad y reglas de evaluación dinámica. Adaptación del modelo y reglas: El sistema implementa 4 capas de validación y reglas de negocio para garantizar la coherencia de los datos y proteger las configuraciones de seguridad infantil. Tres componentes nuevos y su función: JSpinner JRadioButton + ButtonGroup JTextArea + JScrollPane Organización de paquetes y recorrido de una operación: El proyecto está estructurado bajo los patrones MVC (Modelo-Vista-Controlador) y Fachada, manteniendo un desacoplamiento estricto de responsabilidades dentro del paquete base src/ar.edu.ciberseguridad.juegos/: Instrucciones de ejecución, versión de Java y dependencias: El flujo completo de ejecución al dar de alta un nuevo videojuego se desarrolla siguiendo las siguientes etapas secuenciales: • 1.
